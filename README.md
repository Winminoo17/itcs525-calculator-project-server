# ITCS525 Calculator Project Server

This is the backend server for the ITCS525 Mahidol calculator lesson. It provides an API to perform mathematical operations, built with Python.

## Project Structure

- `main.py`: The entry point for the API, containing the route definitions.
- `calculator.py`: Contains the core logic and mathematical operations.
- `models.py`: Data models for API request and response validation.
- `test_main.py` / `test_calculator.py`: Unit tests for the API and calculator logic.
- `.github/workflows/`: Continuous Integration (CI) pipelines for automated testing.

## Prerequisites

- Python 3.8+ (or your specific version)
- pip (Python package installer)
